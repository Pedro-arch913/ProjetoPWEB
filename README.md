## Sobre o Repositório
Este repositório contém o desenvolvimento completo do **Portal Web do JIFAL (Jogos de Integração do IFAL) 2026**. O projeto foi criado como atividade de Programação Web, oferecendo uma plataforma digital que centraliza todas as informações sobre as modalidades esportivas, equipes participantes, galeria de fotos, programação de eventos e histórico do JIFAL.

O portal foi desenvolvido com HTML e CSS puros, garantindo uma estrutura simples, rápida e funcional. Ele inclui múltiplas páginas interativas que permitem aos visitantes explorar informações completas sobre o evento, desde o histórico até as formas de contato com os organizadores.

## Páginas Disponíveis
- 🏠 **Página Principal** - Homepage com informações gerais do evento
- 🏆 **Modalidades** - Descrição detalhada de todos os esportes participantes
- 👥 **Equipes** - Visualização das equipes e jogadores inscritos
- 📸 **Galeria** - Fotos e momentos especiais do JIFAL
- 📋 **Programação** - Cronograma completo de jogos e eventos
- 📚 **Histórico** - Trajetória e história do JIFAL ao longo dos anos
- 📧 **Contato** - Formulário para dúvidas e sugestões

## Como Executar os Arquivos
1. Clone este repositório para sua máquina

    ```
    git clone https://github.com/Pedro-arch913/ProjetoPWEB.git
    ```

2. Navegue até a pasta do projeto

    ```
    cd ProjetoPWEB
    ```

3. Abra o arquivo `pagprincipal.html` no seu navegador (página inicial)

4. Navegue pelas diferentes páginas usando os menus disponíveis

## Estrutura do Projeto
```
ProjetoPWEB/
├── pagprincipal.html      # Página principal
├── paghome.html            # Home com informações gerais
├── pagmodalidades.html     # Modalidades esportivas
├── pagequipes.html         # Equipes participantes
├── paggaleria.html         # Galeria de fotos
├── pagprogramacao.html     # Programação de eventos
├── paghistorico.html       # Histórico do JIFAL
├── pagcontato.html         # Formulário de contato
├── styleg.css              # Estilos principais
├── teladefundo.css         # Estilos de fundo
└── imagensjogos/           # Pasta com imagens do evento
```
